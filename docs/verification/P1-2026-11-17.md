# P1 工程、认证与本地 HTTPS 验证

日期：2026-11-17。结论：P1-01–P1-07 本地实现与验证通过。应用分支为 `feat/p1-foundation`，实现提交范围为 `809c403..9f1b453`，本记录随后随文档提交。提交按工具配置 → 合同客户端 → Go API → 前端 → 联调与 CI → 文档排序；记录对应这组提交中的源码、锁文件及测试。

## 1 实现范围

- 固定项目工具、workspace、依赖锁、格式与 lint；Nuxt 公开站、Vue 管理端、Go API/维护 CLI 独立构建。
- 从既有 OpenAPI 生成 TypeScript 类型，统一超时、取消、错误、CSRF、重试及幂等请求规则；编译级正反例记录条件 schema 的表达边界。
- Go 使用 modernc SQLite、Goose、一个写池和独立读池；启用 WAL、每连接外键与 5000 ms busy timeout。显式迁移，启动只核对 schema。
- 站主初始化、Argon2id 密码、登录/读取/退出、会话轮换、来源与 CSRF 校验、限频、CLI 改密清除全部会话。
- 公开 SSR 只请求公开数据；管理端登录失败保留输入、跨标签同步退出、会话竞态保护和深链接。
- 本地 Caddy HTTPS、隔离 CA、运行目录、日志、进程身份与独占锁、健康检查和失败清理；CI 配置已建立。

P1 实际实现四个合同操作：`GET /api/v1/public/site`、`POST /api/v1/admin/session`、`GET /api/v1/admin/session`、`DELETE /api/v1/admin/session`。内部 `/healthz`、`/readyz` 不经公开代理暴露。原 32 表 SQL 与 58 操作 OpenAPI 没有因本轮实现被改写；其余业务能力按 P2–P7 推进。

### HTTPS 联调

入口：`https://localhost:53772`。证据目录：`var/test/integration-d902967e-101f-4d18-8438-7da83985b7e6/`，含 `result.json`、配置和服务日志；`result.json` 记录 `status=passed`、`checks=9`、`sqlite=3.54.1`。

1. 实际 SQLite 公开配置、单一 `Cache-Control: no-store`、请求追踪，公开访问内部探针返回 404。
2. Nuxt SSR 与管理端深链接正常；未登录会话及其他管理路径返回 401。
3. 错误 Origin 返回 403，未知字段和尾随 JSON 返回 400。
4. 登录返回真实会话；Cookie 为 `__Host-site_session`、Secure、HttpOnly、SameSite=Lax、Path=/、无 Domain；多次读取保持同一 CSRF。
5. 已登录访问公开 SSR，不输出站主 ID、CSRF 或会话 Cookie。
6. 缺失/错误 CSRF 拒绝退出；正确退出返回空体 204，旧会话立即失效。
7. 再次登录轮换旧 token；CLI 改密使两个独立会话均失效。
8. 连续错误密码触发 429 和正数 `Retry-After`。
9. CLI 诊断确认 WAL、外键与 busy timeout，普通日志不含测试密码、session token 或 CSRF。

实际 Go 驱动测试另覆盖四个同时占用的读连接、只读池拒绝写入、BEGIN IMMEDIATE 写锁、失败事务回滚、复合延迟外键失败回滚及最新 schema 记录判断。认证测试覆盖空闲/绝对期限、改密与登录竞争、限频并发及密码 CLI 边界。

## 4 审查修复与故障验证

| 发现与修复 | 验证 |
| --- | --- |
| Go 标准 JSON 解码默认接受大小写别名及重复键；改为严格键检查 | 拒绝大小写、重复/转义同名键、未知字段、非对象、null、错类型、缺字段及尾随内容的 Go 测试通过 |
| 编排可能并发占用同目录、覆盖状态或在启动器退出后遗留后代进程 | 独占运行锁、run_id/进程身份校验、原子状态、guardian 进程组；6 组故障测试中的运行锁、缺失 ps 和忽略 TERM 后代清理均通过 |
| 本地证书可能失效、私钥不匹配，目录可能存在符号链接 | 校验证书/密钥/路径；在原 CA 下修复并续签，已有账号不变；不完整 CA 明确失败，不静默替换 |
| 工具摘要使用 assert 会受 Python `-O` 影响，替换目录中断需恢复 | 显式摘要校验、每工具安装锁及回滚；Python `-O` 错摘要拒绝与中断目录恢复通过 |
| 前端会话旧请求可能覆盖退出或新登录 | epoch/请求序号保护；7 个状态测试通过，多标签真实浏览器验证通过 |
| HTTPS 首次联调发现代理与上游重复 no-store 头 | Caddy 延迟覆盖响应头；真实 HTTPS 断言单一 `no-store` 通过 |
| 固定测试端口被其他项目占用 | 测试改为分配动态空闲端口；不结束无关进程，up 仍校验端口冲突 |
| Firefox 临时 profile 启动时仍需要独立应用数据目录 | 按 Mozilla 支持的环境变量隔离应用目录，保持证书校验，完整浏览器流程通过 |

编排故障测试共 6 组，明确覆盖：缺失 ps、符号链接、同目录锁、启动器退出及端口释放、同 CA 证书修复、工具校验与安装恢复。测试结束检查未发现本项目服务进程、`run/processes.json` 或遗留 `services.lock`；测试服务已停止，运行证据保留。
