## 4 中断、入口和版本检出

代码审查发现仅依赖 try/finally 不能覆盖 Node 默认信号退出。修复在环境创建前注册信号并向 HTTP/启动轮询传递 AbortSignal，重复信号不打断清理；浏览器上下文由统一入口关闭。第一次真实浏览器中断还暴露 Playwright 自身会直接退出，已将其 SIGINT/SIGTERM 处理移交统一生命周期后重新验证。
